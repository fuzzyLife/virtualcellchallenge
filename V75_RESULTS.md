# V75 results: lower profile error, discrimination failure; no release

The development winner profile050 reduced equal-study desired-profile error by **4.68%** (ratio0.953184841), and the remaining-target mean check by **10.22%** (ratio0.897780615). This did not establish a usable overall improvement.

The fixed broader diagnostic covers655 target/context pairs and gives profile error ratio **0.976394512** (2.36% lower), but **PDS change -0.047806962**. Study PDS changes: H1 -0.088333333; Orion -0.033290297; CD4 -0.021797256. The mandatory broad PDS gate fails. No V75 production model or submission was generated and no other gain was promoted after this failure.

Fresh baseline/genuine/shuffle counts completed for the first remaining H1/HCT116 targets, with raw p values, rank checks and original V66 baseline replay. Panel scoring then exposed a cohort-design defect: after reserving three development targets, H1 and HCT116 each have only one remaining unique target. PDS is undefined for a singleton panel, so those count jobs stopped. No complete count/DE confirmation or second-seed result is claimed. The mean results and completed case records are retained.

V76 corrects the statistical panel definition before its count outcomes: all4/4/6/8/8 distinct cases per context for discrimination; only the remaining1/1/3/5/5 for primary profile/DE means. It also tests a different model: dilute the complete normalized response, including direct knockdown. V75 had reduced downstream responses while keeping direct own suppression fixed, changing compositional directions. This is a mechanism hypothesis; superiority requires actual PDS and profile tests. All public biology has been reused, including V75's remaining-target mean data. No new-model confirmation is called blind.
