# V21: Stack vocabulary-compatible response programs

V20's joint arm correctly abstained because its inherited control-variance program basis included too many genes outside the Stack output vocabulary. Its joint/reweight outputs therefore matched the mean arm exactly. We did not loosen the coverage guard or edit V20's frozen code. This follow-up fixes only the incompatible basis and repeats full-count development comparisons. V20 development results were already visible, so this follow-up is not a fresh blind development dataset.

Fit 16 control programs from the top 2,048 adjusted variance genes that are measured by the training sources AND occur in Stack vocabulary. Exclude all 300 panel genes and the entire held query family from program training. Reuse the frozen V20 source prompts, source selection, checkpoint, calibrated mean predictions, shrinkage, seeds and bounds. Independently replay the original generated mean array hashes before deriving new residuals. The mean fields remain bitwise equal to V20.

Project centered paired conditional log1p(CP10k) shifts into these programs. Map each genuine query template cell to a cached query control state, decode the bounded residual back to genes, and change only the .10 empirical component of residual10. Keep the same per-cell library constraints and approximate dual-moment fitting. All 14 target groups now have active programs, with output coverage at least .9858. A matched shuffled-program arm has its Frobenius norm matched to the real program before the same decode, clipping and emission. Reweighting real control occupancy supplies a simpler variation comparator.

The frozen plan is `experiments/v21_stack_programs/analysis/plan.json`, SHA-256 `5c6bb1beb88de1ccb9bd7d792274737955e7fa7c83d85d9fbd46c953ee5fc9b5`. Six arms across the same 28 development cases produce 168 complete-count comparisons. The joint candidate must pass the original raw/worst-family guards, beat amplitude and architecture-matched shuffled controls on two DE measures, and beat both mean-only and occupancy reweighting on two DE measures and centered shape distance. If it fails, V20 mean may proceed only if V20 independently passed its own development assessment. No V21 reserve is opened after a failed development selection.

Root reproduction sequence: `fit_v21_programs.py`, `prepare_v21_experiment.py`, `infer_v21_stack.py development --family <family>` for all three families, `run_v21_experiment.py development --workers 6`, `audit_v21_compatibility.py development`, `audit_v21_experiment.py development`, and `assess_v21_experiment.py development`. Inference uses the isolated Stack runtime; scoring/auditing uses the unchanged competition runtime. Frozen output/assessment files are preserved.

The independent compatibility audit recomputes dense query states, verifies panel exclusion and basis orthogonality, checks parent mean fields bitwise, and verifies active norm-matched shuffled programs. These are tests of a narrow conditional program mechanism, not evidence that full biological variation has been learned. Stack pretraining overlap remains unaudited.
