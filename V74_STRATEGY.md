# V74: calibrate existing V66 response strength in the scoring assay

All four raw-count teacher pilots failed the fixed development gates. V74 retains the V66 response programs instead of moving toward a replacement teacher. It tests fixed 1.15/1.30/1.50 gains on the bulk log1p(50000*p) response residual before own-target suppression, then inverts the assay transformation back into LFCs. Corrections are bounded to 0.375 LFC per coordinate and final effects to +/-3. Own zero, unsupported query genes and zero-response identity are preserved. Own suppression is still applied once by the unchanged residual10 emitter.

This differs from V64's source/V24 LFC vector-norm multiplier: no noisy source norm ratio selects each target's gain, and the transformation acts on the pooled scoring profile rather than multiplying LFCs. It remains a simple calibration experiment, not a new foundation model or new biological evidence. Matched controls add the same gain increment from a cyclically permuted V66 target program.

The identical first-three-unique-target development cohort, >=0.5% equal-study profile-gain threshold, worst-study <=2% degradation and superiority to the matched shuffle are retained. Selection locks before the remaining cases. Generated count profiles, available DE metrics and the broad >=30-cell diagnostic are measured before production. Generated-profile/worst-study/shuffle and broad gates must pass to produce a file; other failed or missing metrics must remain explicit. These are repeatedly reused public datasets and no hidden improvement is guaranteed. D3 remains unopened. No automatic upload or GitHub push.

The estimator and exact frozen rule are in `v74_assay_gain.py` and `analysis/plan.json`. `test_v74_assay_gain.py` verifies gain-one/zero-response identities, missing-gene behavior and correction bounds. Prepare predictions, run development, then confirmation/count/broad/audit stages only if selected. Use the pinned V24 science runtime; official packaging uses the competition environment.
